# ひきだし — 話すためのネタ帳

iPhoneだけでストック／引き出し／反応記録ができるWebアプリです。

## 公開URL
https://shingenmochi0208-oss.github.io/netacho/

> GitHubで `Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save` を設定すると公開されます。公開されるまでは上記URLは動きません。

## iPhoneで使う
1. 上記URLをSafariで開く。
2. 共有ボタンから「ホーム画面に追加」を選ぶ。
3. ホーム画面から開いてネタを保存する。

## データを残したまま更新する
データはブラウザの `localStorage`、保存キー `hikidashi.items.v1` にあります。アプリのHTMLやPWA設定を更新しても、**同じオリジン・保存形式を維持すれば**既存のメモは原則残ります。ブラウザやホーム画面アプリ間で保存領域が分かれる可能性があるため、切り替える際には必ずJSONバックアップを保存し、必要なら復元してください。

ネタの内容はGitHubに送信しません。端末変更・サイトデータ削除・Safariのストレージ消去などに備えて定期的にJSONを書き出してください。現状はクラウド同期はありません。

## 自動バックアップ（v1.1）
メモの追加・編集・削除・お気に入り変更・反応記録ごとに、別のブラウザ内データベース（IndexedDB）へ最大40世代の履歴を保存します。右上のバックアップ画面から過去の状態を選んで復元できます。

注意：自動履歴は**同じ端末・同じWebアプリ内のみ**で利用できます。iPhoneの故障、ブラウザのサイトデータ削除、ストレージ消去には対応しません。JSONを書き出して「ファイル」→「iCloud Drive」に保存しておけば、端末外に控えを残せます。自動iCloud同期は未実装です。

入力欄に表示していた個人的な例文を削除し、中立的な案内文に変更しました。

## GitHubクラウド同期（v1.3・試用版）
アプリ本体は公開リポジトリ `netacho` に置いたまま、個人的なネタは**別の非公開リポジトリ** `shingenmochi0208-oss/netacho-data` の `data.json` に保存できます。

接続方法：
1. GitHubで `netacho-data` を**Private**として新規作成する（アプリの公開 `netacho` とは別）
2. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens で、Repository access を `Only select repositories → netacho-data`、Repository permissions → Contents を `Read and write` にした期限付きトークンを作成
3. iPhoneでホーム画面のひきだしを開き、右上のバックアップ画面で「GitHubクラウド同期（試用版）」にトークンを入力して接続する
4. ほかの端末でも同じURLにアクセスし、各端末で別個のトークンを作成して接続すれば、GitHub上のネタを取得できる

トークンを**チャット・GitHubのコード・README・画面キャプチャ等に絶対に貼り付けない**こと。v1.3からは**「この端末でログイン状態を保持する」**をチェックして接続すると、Web CryptoのAES-GCMで暗号化したトークンと抽出不能な暗号鍵を同じ端末内のIndexedDBに保存し、次回起動時に自動接続します。チェックを外して接続すれば従来どおりセッション中のみの利用です。接続中にチェックを変更することもできます。アプリ内の「切断」で保存情報を消去します。トークンの期限切れやブラウザによるサイトデータ削除時は再入力が必要です。共用端末での保持は推奨しません。トークンをGitHubのコード、README、チャットには記録しないでください。

**セキュリティ上の限界：** 暗号鍵と暗号文を同じオリジンのブラウザ保存領域に保持するため、これは保存時の平文露出を減らす仕組みであって、不正なJavaScript、XSS、端末を操作できる攻撃者に対する強い防御ではありません。権限が`netacho-data`のContents読み書きに限定された期限付きトークンを使い、トークン漏洩時はGitHubで失効させてください。GitHub Pagesは認証サーバーではありません。長期間の自動ログインが必要な場合は、GitHub Appと認証バックエンドを別途導入する必要があります。

接続中の変更は約2秒後にGitHubへ反映を試み、画面復帰時にも同期します。オフラインでは端末内に保存し、再接続後に同期します。競合時はIDと更新日時をもとにマージするため、同じネタを2台から同時編集すると更新日時の新しい方が優先されます。削除情報も同期します。**アプリを終了する前に「同期済み」を確認**してください。未接続時にバックグラウンド同期することはありません。万一に備えJSONバックアップも保持してください。

## v1.7: 壁打ち進捗とChatGPT連携メタデータ

ひきだしの一覧とGitHubのdata.jsonから、各ネタのAI壁打ち進捗を共通の状態として確認できます。

- `review.status`: `unreviewed`（未着手） / `in_progress`（壁打ち中） / `refined`（洗練済み）。未登録の場合は未着手として扱います
- `review.reviewedAt`: 洗練完了のISO 8601日時。`review.startedAt`: 壁打ち開始日時
- `review.source`: `chatgpt`（ChatGPTで合意・反映）または `manual`（アプリで手動設定）
- `review.summary`: 合意したポイント・改善点の短い説明（最大600文字、任意）
- `contentUpdatedAt`: 題名・中身・話し出しが最後に編集されたISO 8601日時。既存ネタは `updatedAt` から補完されます

**画面の派生状態:** `review.status == 'refined'` でも、`review.reviewedAt` より `contentUpdatedAt` が新しい場合は「要再確認」と表示します。これは保存状態を上書きする4つ目の正式ステータスではなく、進捗から計算される表示です。手動で再度「洗練済み」にすると最新の内容を承認できます。

**操作:** ストック一覧に未着手・壁打ち中・洗練済み・要再確認の件数を表示し、状態による絞り込みが可能です。「未完了」は洗練済み以外の合計です。各ネタの詳細画面から壁打ち状態を変更できます。ティア（S/A/B/C）は完成度管理とは別軸です。

**ChatGPTと一緒に壁打ちするとき:** ChatGPTは非公開の `netacho-data/data.json` を読み、ネタのID、現在の内容、`review`、`contentUpdatedAt` を参照します。壁打ち中の状態は会話中の進捗に応じて更新できます。洗練済みへの変更は、内容についてユーザーが納得したことを確認してから、該当ネタの `review.status`, `reviewedAt`, `source: 'chatgpt'`, `summary` および `updatedAt` を更新します。**元の本文を勝手に置き換えません。** GitHubのファイル更新時には最新のblob SHAを確認し、別端末の更新に注意してください。

**旧端末への注意:** v1.6以前のアプリは`review`フィールドを認識しないため、古い画面で同期すると進捗の情報が失われるおそれがあります。複数端末で使用している場合、すべてv1.7以降へ更新してください。

## v1.8.2: 洗練済みを一覧の初期表示に
ネタ一覧は起動時に「壁打ち：洗練済み」が初期選択され、実戦投入前のストックを一覧から隠します。「壁打ち→すべて」で全ストックに戻せます。「要再確認」は自動的に初期一覧から除外します。未着手の登録内容は消えません。

## v1.8.1: 一覧から使いどころタグを編集
ネタ一覧の各タイル／行に「＃」ボタンを追加しました。タップして使いどころを最大3つ選択・解除できます。変更は即時保存、既存の壁打ち状況とティアはそのまま保持します。「＃」の数字は付与中のタグ数を表します。

## v1.8: ネタの使いどころタグ
「アイスブレイク」「本命ボケ」「雑談展開」「深掘り」「つなぎ」の5種類を追加しました。
ネタごとに任意で最大3つまで付与でき、「＋追加」→「使いどころ・話し出し・タグを追加」で登録・編集できます。
ネタ一覧の「使いどころ」から絞り込み可能。詳細画面に選択済みタグを表示し、検索対象にも含めます。
データは各ネタの`roles`配列に保存し、従来の自由タグ`tags`とは分離。既存ネタの`roles`は空配列として扱い、自動分類は行いません。
GitHubクラウド同期のJSONデータ形式は引き続きversion 1。複数端末で使う場合は、端末ごとにv1.8へ更新してください。

## 機能
- 1文からすぐ保存（話題／小ボケ／あるある／その他）
- タグ、場面、話し出し、補足、検索、お気に入り、編集と削除
- ジャンル・場面別のランダム抽出
- 「ウケた／ふつう／いまいち」の反応記録
- JSONファイルでのバックアップ／復元

## 開発
単一の `index.html` にCSSとJavaScriptを同梱しています。サービスワーカー `sw.js` でオフライン閲覧に対応しています。ユーザーデータはリポジトリで管理しません。
